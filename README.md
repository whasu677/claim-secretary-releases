# 실손 청구 도우미 — 설치

보험설계사용 실손보험금 청구 서류 작성·출력·팩스 전송 프로그램.
이 저장소에는 **설치 파일만** 있습니다. 소스 코드는 비공개입니다.

## 받기

[**최신 버전 받기**](../../releases/latest) → 아래에서 본인 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows | `...x86_64-pc-windows-msvc.exe` |
| Mac (애플 실리콘) | `...aarch64-apple-darwin.dmg` |

## 설치

### Windows

1. 받은 `.exe` 를 실행합니다.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 → **추가 정보** → **실행**
   (개발자 인증서를 안 붙여서 뜨는 경고입니다. 설치가 많아지면 사라집니다.)
3. 안내대로 설치하면 바탕화면에 아이콘이 생깁니다.

### Mac

1. 받은 `.dmg` 를 열고 앱을 **Applications** 폴더로 끌어다 놓습니다.
2. 처음 열 때는 **더블클릭이 아니라 우클릭 → 열기** 를 누르고, 뜨는 창에서 다시 **열기**.
   (두 번째부터는 그냥 더블클릭해도 됩니다.)

> 더블클릭하면 *"손상되었기 때문에 열 수 없습니다"* 가 뜰 수 있습니다.
> 앱이 망가진 게 아니라, 애플 공증을 안 받아서 macOS 가 막는 것입니다. 위 방법으로 여세요.

## 업데이트

앱이 켜질 때 새 버전을 확인하고 알려줍니다. 받아서 다시 설치할 필요 없습니다.
